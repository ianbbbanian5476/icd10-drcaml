# 期末報告書審閱筆記

> 針對《應用標籤語意補償機制之ICD-10自動化編碼實作與優化》專題報告書之學術審閱
>
> 日期：2026-05-06

---

## 整體評價

報告結構完整、敘事邏輯清晰、文獻引用紮實（21 篇，含 CAML / PLM-ICD / Longformer / Gradient Checkpointing），三階段實驗演進的敘事架構具說服力。然而與實際實驗數據比對後，存在數個需要釐清的問題。

---

## 一、數據不一致（最關鍵）

| 指標 | 報告宣稱（V6） | 實際 V6OC（最佳） | 落差 |
|------|:---:|:---:|:---:|
| Micro F1 | 67.27% | 61.81% | **-5.46%** |
| Macro F1 | 38.42% | 28.06% | **-10.36%** |

報告中 V6 的 Macro F1 38.42% 比任何實際訓練結果高出超過 10 個百分點。可能原因：

1. **Label map bug**：V6.2 / V6.3 / V6.4 歷史評估使用錯誤 label map（V5 的 2,099 labels 去評估 MIMIC 的 2,496 labels），修正後 V6.4 從 36.45% → 41.44%。若報告的 V6 數據來自修正前的錯誤評估，則 67.27%／38.42% 可能存有類似問題。
2. **V6 與 V6OC 是不同模型**：報告中的 V6 使用 BCE Loss，V6OC 使用 Focal Loss——但報告全文未提及 Focal Loss。若 V6 確實僅為 BCE + DR-CAML，則 Micro 67.27% 的 BCE 版本是否存在需要確認。

> **建議**：追溯表 1.2 中 V6（67.27%／38.42%）的實際權重檔與評估日誌，確認評估協議無 bug。

---

## 二、Focal Loss 完全缺席

報告描述的 V6 = BERT 512 + DR-CAML + BCE。但實際實驗中，**V6OC (DR-CAML + Focal Loss)** 才是真正的核心突破：

- V6OC Micro F1 = 61.81%，Macro = 28.06%（+6.13% vs V5.1）
- V6OC 最佳 TH = 0.40（Focal Loss 使信心分佈右移，與 V5.1 的 TH=0.30 不同）

Focal Loss 是處理 2,099 labels 長尾分佈的關鍵技術選擇，在學術寫作中應被明確討論。目前報告的 narrative 是「DR-CAML 語意補償」解決了問題，但實際貢獻可能部分是 Focal Loss 的類別加權效果。

> **建議**：若要在報告中維持現有 narrative，至少需在實驗設計章節補充 Focal Loss 的消融對比，否則審稿者會質疑「DR-CAML 貢獻」與「Loss function 貢獻」的混淆。

---

## 三、對 Longformer 的定論可能過早

報告將 V3.1 / V5（Longformer）描述為「單純擴展序列長度對特徵擷取增益有限」，在當時的實驗條件下 Micro F1 僅 29.35%。但後續發現：

> Longformer V3.1 歷史評估協議可能同樣有 label map bug，不該過早判死刑。

若 V3.1 也被錯誤 label map 評估，其 29.35% 可能被低估。這對報告的核心 narrative（Longformer 失敗 → BERT + DR-CAML 成功）有直接影響——若 Longformer 並未真正失敗，整個故事線需要調整。

> **建議**：以正確評估協議重驗 V3.1 Longformer，再決定報告中的定論。

---

## 四、Ablation 貢獻缺乏量化

報告多次強調「資料清洗」與「DR-CAML」的貢獻，但以文字描述為主，缺乏量化消融數據。實際 ablation study 結果：

| 因素 | 貢獻 |
|------|:---:|
| 資料清洗（F碼排除 + 四碼降維 + MIN_FREQ） | **+25.76%** |
| DR-CAML | **+1.87%** |

這組數字對論文極為有利——清楚展示了資料工程的決定性貢獻。報告中應加入此量化分析。

---

## 五、其他觀察

### 值得保留的部分

- **R@K 分析**（R@15 = 86.7%）具臨床實務說服力，是報告亮點
- **表 4.2** 與 DR-CAML / PLM-ICD 的對比結構清楚
- **F 碼排除**的文獻支撐充分（94% 主診斷偏好）
- **Gradient Checkpointing** 的技術說明完整

### 需注意的部分

- **第五章（結論）** 全為「仍在實驗中」，為報告最大缺口
- V5.1 Micro F1 = 63.72% 與 V6OC TH=0.3 的 61.19% 接近，但報告未討論 V6OC 的存在
- **Micro AUC 98.96%** 可能來自 label imbalance 虛高（高頻 label 主導），建議補充 per-label AUC 分佈分析
- MIMIC 對比僅在文獻回顧提及，未有自身實驗數據
- **Co-occurrence post-hoc correction** 經 6 組參數測試全降 F1，已放棄——此 negative result 在論文中也有價值
