## 一、V6 與 V6OC 的區分

> **❌ 初審誤判**：原先將 V6（67.27%）與 V6OC（61.81%）混為一談，認定數據不一致。經釐清後修正如下。

**V6 與 V6OC 是兩個獨立實驗**：

| 模型 | Loss | 資料集 | Micro F1 | Macro F1 | 狀態 |
|------|------|--------|:---:|:---:|------|
| **V6** | BCE + DR-CAML | 榮總 | **67.27%** | **38.42%** | 權重誤刪 |
| **V6OC** | Focal Loss + DR-CAML | 榮總 | 61.81% | 28.06% | 權重存在 |

**關鍵事實**：
- V6 的 67.27%／38.42% 是真實成績，訓練腳本即目前 V6.4 腳本（只需將 V6.4 引用的 MIMIC-IV dataset 替換回榮總 dataset 重新訓練即可復現）
- V6 模型權重因操作失誤被刪除，目前無法直接載入驗證，需重訓
- V6.4 是因應 MIMIC 資料集而調整的版本，非原始 V6
- V6OC 使用 Focal Loss 為獨立實驗線，成績低於 V6 的 BCE 版本

> **建議**：安排 GPU 空檔重訓 V6 並保存權重，以確保報告成績可驗證、可追溯。

---

## 二、Focal Loss 與 V6OC 實驗線未納入報告

報告描述的 V6 = BERT 512 + DR-CAML + BCE。然實際另有一條獨立的 **V6OC (DR-CAML + Focal Loss)** 實驗線：

- V6OC Micro F1 = 61.81%，Macro = 28.06%（低於 V6 的 BCE 版本）
- V6OC 最佳 TH = 0.40（Focal Loss 使信心分佈右移，與 BCE 的 TH=0.30 不同）
- V6OC 為 Focal Loss 在長尾 ICD-10 分類上的首次嘗試，具有技術探索價值

Focal Loss 是處理 2,099 labels 長尾分佈的重要技術選項，即使 V6OC 成績低於 V6（BCE），其作為 negative/discovery result 仍具學術記錄價值。目前報告完全未提及此實驗線。
1.2.3.


> **建議**：若報告篇幅允許，可在實驗設計章節補充 V6OC 作為 ablation variant，對比 BCE vs Focal Loss 在此任務上的效果差異。

## 三、對 Longformer 的定論可能過早

報告將 V3.1 / V5（Longformer）描述為「單純擴展序列長度對特徵擷取增益有限」，在當時的實驗條件下 Micro F1 僅 29.35%。但後續發現：

> Longformer V3.1 歷史評估協議可能同樣有 label map bug，不該過早判死刑。

若 V3.1 也被錯誤 label map 評估，其 29.35% 可能被低估。這對報告的核心 narrative（Longformer 失敗 → BERT + DR-CAML 成功）有直接影響——若 Longformer 並未真正失敗，整個故事線需要調整。

> **建議**：以正確評估協議重驗 V3.1 Longformer，再決定報告中的定論。

---

## 四、Ablation 貢獻缺乏量化

報告多次強調「資料清洗」與「DR-CAML」的貢獻，但以文字描述為主，缺乏量化消融數據。實際 ablation study 結果：

| 因素 | 貢獻 |
|------|:---:|
| 資料清洗（F碼排除 + 四碼降維 + MIN_FREQ） | **+25.76%** |
| DR-CAML | **+1.87%** |

這組數字對論文極為有利——清楚展示了資料工程的決定性貢獻。報告中應加入此量化分析。

## 五、其他觀察

### 值得保留的部分

- **R@K 分析**（R@15 = 86.7%）具臨床實務說服力，是報告亮點
- **表 4.2** 與 DR-CAML / PLM-ICD 的對比結構清楚
- **F 碼排除**的文獻支撐充分（94% 主診斷偏好）
- **Gradient Checkpointing** 的技術說明完整

### 需注意的部分

- **第五章（結論）** 全為「仍在實驗中」，為報告最大缺口
- V5.1 Micro F1 = 63.72% 與 V6OC TH=0.3 的 61.19% 接近，但報告未討論 V6OC 的存在
- **Micro AUC 98.96%** 可能來自 label imbalance 虛高（高頻 label 主導），建議補充 per-label AUC 分佈分析
- MIMIC 對比僅在文獻回顧提及，未有自身實驗數據
- **Co-occurrence post-hoc correction** 經 6 組參數測試全降 F1，已放棄——此 negative result 在論文中也有價值
