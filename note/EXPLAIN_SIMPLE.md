# 用白話搞懂你的模型 — 委員問題簡單版

> 不用數學系學位也能讀懂。所有重點都在，只是換成日常語言。
>
> 日期：2026-05-07

---

## 你的模型在做什麼？（一句話版本）

電腦讀完一份病歷 → 從 2,099 種可能的疾病代碼中，選出「這個病人應該被標哪些 ICD-10 代碼」。

---

## 模型的三個零件

想像你是一位編碼人員，桌上放著一份病歷：

### 零件一：閱讀器（BERT）

就像你快速掃過病歷文字，BERT 把每個字轉成一個數字向量（768 個數字的清單），用來代表這個字的「意思」。整份病歷變成一個數字矩陣 H。

### 零件二：搜尋引擎（Label-Aware Attention）

現在有 2,099 種疾病，每種疾病都需要在病歷裡「找到和自己有關的段落」。

- 高血壓（I10）應該去看血壓那段
- 糖尿病（E11.9）應該去看血糖那段
- 心臟病應該去看心臟那段

模型為每個疾病配備一個「探照燈」——它會掃描整份病歷，自己學會要照亮哪些字。這 2,099 個探照燈互不干擾。

### 零件三：分類器（Classification Head）

探照燈找到相關字之後，把這些字的數字向量加權平均，得到一個代表「這疾病有多像」的分數。分數經過 sigmoid（一個數學閘門）轉成 0 到 1 之間的機率。> 0.5 就判定「有這個病」。

---

## 這和舊方法差在哪？

### 舊方法（CLS）：一本書一個摘要

```
┌─────────────┐
│   整份病歷    │ → 壓成一個向量 → 一次判斷 2,099 種病
└─────────────┘
```

**問題**：高血壓這種超常見的病（出現 9.5 萬次）會「蓋住」罕見病的微弱信號。就像全班平均分數很高，不代表每個人都及格。

### 新方法（DR-CAML）：一本書 2,099 個摘要

```
         ┌→ 探照燈 1（高血壓）→ 看血壓相關段落 → 判斷高血壓
一份病歷 ─┼→ 探照燈 2（糖尿病）→ 看血糖相關段落 → 判斷糖尿病
         └→ 探照燈 2099（某罕病）→ 看特定段落 → 判斷該罕病
```

**效果**：罕見病不再被高頻病淹沒。這就是 Macro F1 從 22% 跳到 38% 的原因。

## Loss Function 到底是什麼？（白話）

訓練模型就像教小孩認字——你需要告訴他「答對了嗎？」

Loss function = 錯誤計算機。數字越小 = 模型越準。

### 第一部分：分類錯誤（BCE Loss）

```
如果病人真的有高血壓（答案 = 1），模型猜 0.2 → 錯很大 → 扣很多分
如果病人真的有高血壓（答案 = 1），模型猜 0.9 → 幾乎對 → 扣很少分
```

對 2,099 個疾病都算一遍，加總就是分類錯誤。

### 第二部分：知識偏差（Regularization）

模型在學「高血壓長什麼樣子」的時候，如果這個病在資料裡只出現 30 次，樣本太少，學不到東西。怎麼辦？

我們事先準備了一份「標準答案表」——把 ICD-10 官方對每種疾病的描述文字餵進 BERT，算出每個疾病「理論上應該長什麼樣子」。然後告訴模型：

> 「你學出來的東西，不要離標準答案太遠。」

這就是 regularization。它像老師在旁邊說：「你這個答案方向是對的，再微調一下就好。」

### 完整 Loss

```
總錯誤 = 分類錯誤 + λ × 知識偏差
```

λ 是控制「老師的話有多重要」的旋鈕（V6 設為 0.01）。

---

## 為什麼 Macro F1 進步這麼多？

Macro F1 = 2,099 種疾病的「平均成績」。

### 舊模型（V5.1 CLS）：偏科學霸

| 疾病類型 | 表現 | 原因 |
|---------|------|------|
| 常見病（高血壓、糖尿病）| 🟢 很好 | 樣本多，隨便學都會 |
| 罕見病（出現 <50 次）| 🔴 幾乎不會 | 被常見病蓋台 |

→ Macro F1 = 21.93%（被罕見病拖垮）

### 新模型（V6 DR-CAML）：科科及格

**武器一**：2,099 個獨立探照燈 → 罕見病有自己的專屬檢索器，不用跟高血壓搶注意力。

**武器二**：知識偏差當家教 → 樣本太少沒關係，標準答案表幫你補課。

→ Macro F1 = 38.42%（+16.49%）

### 實例：為什麼 R@15 也進步了？

R@15 = 模型列出 15 個最可能的疾病，其中包含正確答案的機率。

舊模型 R@15 = 85.13%，新模型 = 86.70%。進步 1.57%。

這 1.57% 聽起來不多？但它來自**最難的那批病歷**——病人同時有很多病、病歷寫得模糊、資訊分散。在這些高難度個案上，獨立探照燈 + 標準答案表的組合特別有效。

## BCE vs Focal Loss：兩種扣分方式

模型訓練就像學生寫考卷，Loss function 決定「怎麼打分數」。

### 場景設定

你的資料有 2,099 種疾病。其中：
- **常見病（高血壓 I10）** 出現 95,000 次 → 模型考這題考了 95,000 遍，早就會了
- **罕見病（某心臟病）** 出現 30 次 → 模型幾乎沒練習過，一直答錯

### BCE Loss（公平老師）

> 「每題一樣重，錯一題扣一分。」

```
常見病答錯 → 扣 1 分
罕見病答錯 → 扣 1 分
```

**結果**：常見病有 95,000 題，罕見病只有 30 題。模型發現「只要把常見病練好，總分就會高」，於是放棄罕見病。

→ V5.1 用 BCE：Micro F1 63.72%（常見病很強）／Macro F1 21.93%（罕見病被放生）

### Focal Loss（偏心老師）

> 「你已經會的題目，錯了不怎麼扣；你一直不會的題目，錯了扣超重。」

```
常見病答錯 → 模型信心 0.01（幾乎確定答對，只是小失誤）→ 扣 0.0001 分
罕見病答錯 → 模型信心 0.98（以為自己對，其實錯很大）→ 扣 5 分
```

Focal Loss 用一個公式自動判斷：「這題你是不是已經會了？」

$$\text{扣分} = \underbrace{-\log(\hat{y})}_{\text{基本的錯}} \times \underbrace{(1 - \hat{y})^\gamma}_{\text{信心懲罰}}$$

- $\hat{y}$ = 模型猜的機率（0~1）
- $\gamma$ = 偏心程度（我們設 $\gamma = 2$）

當模型對常見病已經很有把握（$\hat{y} \to 1$），$(1-\hat{y})^\gamma$ 趨近 0 → 幾乎不扣分。
當模型對罕見病仍然亂猜（$\hat{y} \to 0$），$(1-\hat{y})^\gamma$ 趨近 1 → 照常扣分，強迫模型注意它。

### 實際效果對比

| | BCE（公平） | Focal（偏心） |
|------|:---:|:---:|
| 常見病表現 | 🟢 超強 | 🟡 略降（沒被逼著練） |
| 罕見病表現 | 🔴 放棄 | 🟢 被逼著學 |
| Micro F1 | 63.72% | 61.81% |
| Macro F1 | 21.93% | 28.06% |
| 適合情境 | 每種病一樣重要 | 罕見病不能放棄 |

### 一句話

> BCE 讓模型當「常見病專家」。Focal 強迫模型當「全科及格生」——代價是常見病稍微退步，但罕見病終於學會了。

## λ 旋鈕：老師的話要多聽？

λ 就是控制「標準答案表有多重要」的旋鈕。數字越大 = 老師越嚴格 = 模型被強迫靠近標準答案。

### V6：λ = 0.01（老師講小聲）

> 老師說：「你盡量自己學，我只是輕輕提醒你不要跑太遠。」

| 效果 | 原因 |
|------|------|
| 🟢 Micro F1 高（67.27%）| 常見病樣本夠多，模型自己學就很準 |
| 🟢 Macro F1 高（38.42%）| 溫和引導剛好讓罕見病有基本方向 |
| 🟡 對資料依賴強 | 資料品質決定一切 |

### V6OC：λ = 0.10（老師講大聲）

> 老師說：「你不確定的時候，看我給的答案！」

| 效果 | 原因 |
|------|------|
| 🟡 Micro F1 低（61.81%）| 常見病被強迫靠近標準答案，反而沒有完全發揮資料的優勢 |
| 🟡 Macro F1 低（28.06%）| 嚴格引導反而過度約束，罕見病的少量樣本資訊被標準答案蓋掉 |
| 🟢 對資料依賴較弱 | 即使資料少，標準答案能補 |

### 為什麼兩個版本用不同 λ？

```
V6（λ=0.01）|        —— 搭配 BCE Loss → Loss 只算「對不對」
                        輕微引導剛好

V6OC（λ=0.10）|       —— 搭配 Focal Loss → Loss 會刻意重視難的案例
                        需要更大的 λ 來對抗 Focal Loss 的「偏心」
```

**白話版**：
- BCE 是公平的老師：每個疾病錯一樣扣一樣多分
- Focal Loss 是偏心的老師：簡單病（已經學會的）錯就少扣點，難的病（一直學不會的）錯就用力扣

Focal Loss 把注意力拉去難的病，如果 λ 太小，模型連「這疾病長什麼樣子」的基本方向都忘了。所以 V6OC 把 λ 調到 0.10，確保模型心裡還有標準答案的在。

### 一句話記住

| λ | 感覺 | 適合 |
|:---:|------|------|
| 0.01（V6）| 「自習為主，老師講兩句」| 資料充足、Loss 公平 |
| 0.10（V6OC）| 「老師放大聲公」| Loss 偏心（Focal），需要平衡 |

## 名詞對照表（中英 / 專業 ↔ 白話）

| 專業名詞 | 白話意思 |
|---------|---------|
| Hidden State（H）| BERT 讀完每個字後的「理解」 |
| Attention Weight（A）| 探照燈亮度（0~1，越亮越相關） |
| Label-Specific Feature（V）| 某疾病從病歷中「看到的重點」 |
| Classification Weight（W）| 模型自己學會的「疾病模板」 |
| Label Embedding（E）| 標準答案表（事先算好，不變） |
| BCE Loss | 分類錯誤分數（公平老師：每題錯一樣重） |
| Focal Loss | 分類錯誤分數（偏心老師：簡單題錯輕罰，難題錯重罰） |
| Regularization | 知識偏差分數 |
| λ (lambda) | 控制「標準答案表有多重要」的旋鈕（0.01 = 小聲提醒，0.10 = 大聲公） |
| Sigmoid | 把分數壓成 0~1 機率的數學閘門 |
| Micro F1 | 所有預測的總體正確率 |
| Macro F1 | 2,099 種疾病的平均正確率 |
| R@15 | 給出 15 個建議，命中正確答案的機率 |

## 一句話總結你的貢獻

> 我們不是讓電腦變更聰明，而是讓它學會「每種疾病分開看，並且用醫學常識補課」。結果：罕見病的辨識力從幾乎是 0 變成可以用的水準。
