## 三、Longformer 驗證結果

### 3.1 V3.1 重驗

以正確評估協議（label_map_v2.json / val_v2.json / threshold sweep）重驗 V3.1 現有權重。

| TH | Micro F1 | Precision | Recall | Active Labels |
|:---:|:---:|:---:|:---:|:---:|
| 0.50 | 0.00% | — | 0.00% | 0 / 14,789 |
| 0.30 | 0.00% | — | 0.00% | 0 / 14,789 |
| 0.20 | 8.97% | 24.63% | 5.48% | 1 / 14,789 |
| 0.10 | 13.97% | 17.44% | 11.65% | 3 / 14,789 |
| 0.05 | 13.25% | 12.58% | 14.00% | 5 / 14,789 |

AUC = 0.9591。模型僅對 1-5 個 label 有信心輸出，本質上已失效。

### 3.2 Longformer 結論

原始評估（TH=0.10, 14%）為準確結果，非 label map bug 所致。14,789 dirty labels 導致模型無法學習有效特徵表示。Longformer 1024 的滑動窗口注意力對多標籤稀疏分類無明顯增益。

## 四、Token 長度分析

| 指標 | MIMIC-IV | 榮總 |
|------|:---:|:---:|
| Token 中位數 | 3,207 | 422 |
| 512 token 覆蓋率 | 0.2% | 64.4% |
| 1024 token 覆蓋率 | — | 96.0% |

榮總病例多為中短文本，512 token 已覆蓋 64.4% 案例。1024 token 可多覆蓋的 31.6% 案例本質為長文本複雜病例，預測難度較高。

## 五、Co-occurrence Post-hoc Correction

經 6 組參數測試（threshold 0.1-0.9, top-k 3-10），所有組合均導致 Micro F1 下降（61.81%→最低 61.43%）。結論：模型已從訓練資料內化學到標籤共現關係，外部校正反而過度修正。**此方向已放棄。**
